    Settings reference

    This reference is generated from the settings registry of ncode itself, so it lists exactly the keys that Settings shows and ncode config accepts.

    How to read it:

    • Key is the name for ncode config get, set and reset, and for /settings <key>.
    • Scope is where the value is kept: global (the database the desktop app shares), project (this project), session (one conversation), cli (cli.json, this terminal only) or project_file (.swarm_code/config.json, read-only here).
    • Applies says when a change takes effect, for example at once, next turn, next spawn (the next agent started), next launch, or desktop when only the desktop app acts on it.
    • Override names a flag or environment variable that wins while it is set.

    Scopes: global (the database, shared with the desktop app), project (the project row), session (this conversation), cli (cli.json, this terminal only), project_file (.swarm_code/config.json, read-only here).

    Override: the environment variable or flag that wins over the stored value. The older SWARM_* name of each NCODE_* variable still works; when both are set, NCODE_* wins.
