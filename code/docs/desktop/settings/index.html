    ncode Desktop / Customize

    Settings

    Open Settings with ⌘+,, the gear at the bottom of the rail, or File → Settings… in the menu bar. The sections are listed on the left; click one to jump to it. Most changes apply at once; forms with several fields have their own Save button.

    General#

    The Defaults card: which models new conversations start with (Chat model, Sub agent model, Default scheduled model, Default workflow model, Implementer model (consensus)) and the default reasoning effort for chat, scheduled tasks, workflows, swarms and the implementer. Click Save defaults after changing a model. See Providers, models and web search.

    Deep research#

    The Search providers used by all web searches (engines and readers, their keys and their order), the default research level, limits, domain filters, the lead, worker and reporter models, and when the designed report is built. See Providers, models and web search and Deep research.

    Appearance#

    Theme and dark or light mode, Reduce motion, the default consensus card layout, Bring the window to front when a run finishes, Show global scheduled tasks, and whether the "Worked for…" and "Thinking" disclosures start open. See Themes.

    Providers & models#

    Your model endpoints: add, edit, delete, Fetch models, and the effort levels each provider offers. See Providers, models and web search.

    Pricing#

    A price per million tokens for each model (input, output, cache read, cache write) and its context window, so runs show their cost.

    MCP servers#

    Add MCP servers, scope them to a project, switch them or single tools on and off, reconnect them. See MCP servers.

    Memory#

    Edit a project's memory and your global memory. See Instructions, memory and project config.

    Storage#

    How much space ncode's data takes, Clean up…, and retention. See Storage and cleanup.

    Commands#

    Your custom slash commands, project and global: New command, Open project commands, Open global commands. See Commands, agents and skills.

    Keybindings#

    Change the nine app shortcuts. See Keyboard shortcuts.

    Agents#

    The agent definitions ncode found (bundled, yours and the project's), read-only. See Commands, agents and skills.

    Limits#

    How many agents may run, how deep and how long; command and tool timeouts; workflow budgets; sub-agent isolation; the environment of the agents' shell; and the list of approved commands. See Limits and isolation and Approvals and trust.

    Budget#

    Monthly budget (USD): a spend target. The bar on the Usage history page fills against it; nothing is blocked when it runs out.

    Settings from a project#

    A project can bring hooks and profiles in its own file. See Instructions, memory and project config.
