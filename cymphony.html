Cymphony

Turn Linear tickets into autonomous coding sessions. You manage work, not agents.

A modern rewrite of openai/symphony, powered by Claude Code. Drop a ticket into "Todo" and Cymphony picks it up, spins up a sandboxed workspace, and lets Claude Code work on it until the issue closes — then opens a pull request for your review.

Cymphony — Operations
Why Cymphony

Everything openai/symphony does — plus what a small team needs

The core idea is the same: tickets become coding sessions. Cymphony adds the pieces that turn it from a single-developer toy into something a team can lean on.

  • Claude Code as the coding agent instead of Codex
  • One command from anywhere — cymphony launches the orchestrator + dashboard; cymphony start runs it as a daemon
  • Multi-project orchestration with a per-project cap on concurrent sessions, changeable live
  • Custom Claude command per project — point one at the official CLI, another at a credential-swapping wrapper
  • Rotate across Claude-compatible backends to avoid any single provider's rate limit
  • Phoenix LiveView dashboard — kill, retry, pause, and set-provider per running session
  • HTTP API — /api/v1/* for state, pause, concurrency, providers, and refresh
  • Workspace lifecycle hooks and an optional retention sweep, plus optional bearer-token auth
Two Ways To Watch

Same data, browser or terminal

A real-time Phoenix LiveView dashboard when you want controls, and a grouped terminal status when you want to stay in the shell.

How It Works

Review like it's a human teammate

Cymphony isn't a one-shot dispatcher. Because it reuses one workspace per issue, the agent keeps full context across rounds — your feedback lands on top of everything it already knows.

1

Drop a ticket

Move a Linear ticket into "Todo". On the next poll, Cymphony spins up an isolated workspace and the agent gets to work.

2

It opens a PR

When it's done it pushes a branch, opens a pull request, and moves the ticket to your terminal state.

3

You review & comment

Something off? Don't open a new ticket — comment on the same issue and move it back to an active state.

4

It resumes the branch

Cymphony reuses the same workspace and branch, reads your comment, applies the feedback, and force-pushes to the existing PR.

5

Repeat until merge

Iterate as many rounds as you like. You never pay for a fresh re-read of the codebase — context carries over each time.

↻

You manage work, not agents

The whole loop runs against your existing Linear board — no new tool for your team to learn.

Provider Rotation

Run more sessions without hitting a wall

Parallel sessions hit upstream rate limits fast. Cymphony spreads them across multiple Claude-compatible backends — Anthropic's official API, z.ai (GLM), Kimi (Moonshot), OpenRouter, or any Anthropic-compatible vendor. List two or more and new sessions are distributed at random.

  • Configure via shell functions or plain JSON — whichever fits how you already work
  • Set providers per project, or per session live from the dashboard
~/.cld — one function per backend 
# each fn name starts with "c" (Cymphony's rule)
cz()  { _unset; export \
  ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic \
  ANTHROPIC_API_KEY=$ZAI_KEY; }

ck1() { _unset; export \
  ANTHROPIC_BASE_URL=https://api.moonshot.ai/anthropic \
  ANTHROPIC_API_KEY=$KIMI_KEY; }

# point a project at "cz, ck1" — Cymphony
# rotates new sessions across them.

Install

Up and running in one line

Erlang is bundled, so there are no system dependencies to manage. After installing, run cymphony once and an interactive wizard walks you through your first project.

macOS — Homebrew 
brew tap zaalipro/cymphony
# bundles Erlang/Elixir, zero system deps
brew install cymphony
# or smaller, uses your existing Elixir:
brew install cymphony-lite

cymphony   # first run → setup wizard
Ubuntu / Debian 
# Cymphony needs the Claude CLI on $PATH
npm install -g @anthropic-ai/claude-code

wget https://github.com/zaalipro/cymphony/\
releases/latest/download/cymphony_amd64.deb
sudo dpkg -i cymphony_amd64.deb

Ship from your Linear board

Already running openai/symphony? Switching is mostly: install Cymphony, run cymphony setup, and paste your Linear API key. Then manage work, not agents.
